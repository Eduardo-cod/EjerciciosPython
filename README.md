# 📘 Python Crash Course - Eric Matthes

Este repositorio contiene la realización de los ejercicios y proyectos del libro **"Python Crash Course"** de **Eric Matthes**, una guía práctica diseñada para aprender Python mediante la práctica constante y el desarrollo de proyectos.

El objetivo de este repositorio es documentar mi progreso, reforzar conceptos fundamentales de programación y mantener un registro organizado de cada capítulo a medida que avanzo en el aprendizaje de Python.

---

## 📂 Contenido del repositorio

Cada carpeta corresponde a un capítulo del libro e incluye:

- ✅ Ejercicios resueltos
- ✅ Notas y comentarios personales
- ✅ Código limpio y funcional
- ✅ Prácticas adicionales cuando aplica

---

## 🛠️ Tecnologías utilizadas

- Python 3.x
- Visual Studio Code (VS Code)
- Git
- GitHub

---

## 🎯 Objetivos del proyecto

- Practicar Python desde un nivel principiante hasta intermedio.
- Comprender y aplicar conceptos fundamentales como:
  - Variables y tipos de datos
  - Estructuras condicionales
  - Bucles y ciclos
  - Funciones
  - Clases y programación orientada a objetos
  - Manejo de archivos
  - Módulos y paquetes
- Desarrollar buenas prácticas de programación.
- Documentar públicamente mi proceso de aprendizaje.

---

## 🚀 Cómo ejecutar los ejercicios

### 1. Clonar el repositorio

```bash
git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
```

### 2. Acceder al capítulo que deseas revisar

```bash
cd capitulo_03
```

### 3. Ejecutar el archivo Python

```bash
python ejercicio_3_1.py
```
