Este repositorio contiene la realización de los ejercicios del libro “Python Crash Course” de Eric Matthes, una guía práctica para aprender Python mediante proyectos y práctica constante.
El objetivo es documentar mi progreso, reforzar conceptos fundamentales y mantener un registro organizado de cada capítulo.

Cada carpeta incluye:
-Ejercicios del capítulo
-Notas o comentarios personales
-Código limpio y funcional

Tecnologías utilizadas
-Python 3.x
-VS Code
-Git & GitHub

Objetivo del proyecto
-Practicar Python desde cero hasta un nivel intermedio
-Comprender conceptos clave como:
    -Variables y tipos de datos
    -Condicionales y ciclos
    -Funciones
    -Clases y objetos
    -Manejo de archivos
    -Módulos y paquetes
-Desarrollar buenas prácticas de programación
-Documentar mi aprendizaje de forma pública

Cómo ejecutar los ejercicios
-Clona el repositorio:
    -git clone https://github.com/TU_USUARIO/TU_REPO.git
-Entra a la carpeta del capítulo que quieras revisar:
    -cd capitulo_03
-Ejecuta el archivo Python:
    -python ejercicio_3_1.py

Notas
-Este repositorio es únicamente para fines educativos.
-El contenido del libro no se incluye, solo mis soluciones y prácticas.
